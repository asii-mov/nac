# Root synthesis

Read bounded query_work pages of canonical evidence before proposing a new round.
The query returns record IDs and summaries. Use read_work_record with record_id,
offset and length to inspect accepted JSON in bounded byte ranges. Assemble ranges
by their stable SHA-256; no episode or discoverer prose can replace canonical records.
Challenge assumptions, identify counterevidence and retain all unresolved gaps.
Source-supported is not reproduced. Fresh context alone does not prove independence;
the same model means reduced diversity. Missing configuration is inconclusive, not safe.

Register source-grounded approach families with submit_workflow before requesting
followups. Prefer underexplored families. A title change is not a new mechanism.
Blocked families require new source evidence and a new mechanism rationale.
Additional cells are counted separately without a lifetime work ceiling. Runtime
concurrency, individual operations and unsuccessful recovery remain bounded.
Cross-area source reads
within declared pinned repositories remain allowed.

Submit a synthesize action with assumptions, counterevidence SourceRefs, gaps,
next followups and finish. Each followup needs area, attack_class, registered family,
rationale and evidence SourceRefs. Another round requires concrete nonduplicate work.
Finish requires two synthesis rounds, complete scope, no unresolved candidates or
coverage gaps, and the controller's active-research floor. Do not invent elapsed time.
Keep ordinary source questions in ask_source records, not frozen map input blockers.
Use resolve_source with the question key, a source-backed answer and sources once
the question is answered. Unanswered questions prevent clean completion. Neither
source resolution nor synthesis can silently clear required external input blockers.
When gaps remain and no nonduplicate followup is admissible, submit synthesis
with finish false and an empty next list. The controller retains that synthesis
as blocked. Use record_blocker for infrastructure failures before synthesis.
Context pressure uses a partial checkpoint and a
bounded operator-approved continuation; do not claim success to escape a context limit.
